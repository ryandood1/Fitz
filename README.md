# Fitz's Playground

A kid-friendly web app with four games: Draw, Count It, Match and Pop. Wins fill a star jar.

Open `index.html` in any browser. No install needed. Change the name in the `KID` constant near the top of the script.

## Brown Bear Color Hunt

`color-hunt/index.html` is a hide-and-seek coloring book game inspired by the animals in *Brown Bear, Brown Bear*. Find the hidden animals in eight pictures (Meadow, Farm, Pond, Backyard, Beach, Snowy Hill, Starry Night, Forest). Each tap colors the animal in with a crayon scribble, and faster finds earn more points. Finish a picture and the whole page colors itself in.

## Cookie Kitchen

`cookie-kitchen/index.html` is a picture-first baking game for early readers. Pick a bowl, drop in the ingredients and a flavor, stir with a spoon, whisk or mixer, add yummy bits, cut shapes onto the tray, bake with an oven mitt, then frost, sprinkle and add googly eyes. Tap the finished cookies to eat them. A pointing finger shows what to tap next, and every batch goes in the cookie jar on the start screen.
